4. Visiting the website and server logs

When you visit this website, our server necessarily processes the following data sent by your browser: IP address, date and time of the request, requested address (URL) including query parameters such as language, filters or search terms, HTTP status code, amount of data transferred and browser identifier (user agent). 5. Loading content from the Campus API

The news, events, channels, images and public calendar entries shown come from the Student Body’s Campus API, which also powers the “Campus Köthen” app. The Campus API imports calendar entries server-side from the student bodies’ public Google calendars; visiting this website does not connect your browser to Google. Your browser does not connect to the Campus API directly: our web server retrieves the content on your behalf for every request and delivers it to you without caching it. Your IP address and browser data are not passed on to the Campus API; only the requested language and page number are transmitted. The Campus API has no user accounts and creates no usage profiles. Legal basis: Art. 6(1)(e) GDPR in conjunction with § 65(1) HSG LSA.

Selected filters and search terms are not stored; they only appear in the address bar so you can share a view. No cookies are set.
